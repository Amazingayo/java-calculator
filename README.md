Java Calculator

A simple console-based calculator built with Java. This project was created to practise Java fundamentals while building a working program.

Features

* Addition
* Subtraction
* Multiplication
* Division
* Handles invalid user input
* Prevents division by zero
* Allows repeated calculations until the user exits

Technologies Used

* Java
* Java Scanner for user input

How to Run

1. Clone the repository

git clone https://github.com/Amazinggayo/java-calculator.git

2. Navigate to the project folder

cd java-calculator

3. Compile the program

javac Calculator.java

4. Run the program

java Calculator

What I Practised

* Variables and data types
* User input with Scanner
* Conditional statements
* while loops
* switch statements
* Methods and program flow
* Exception handling with try and catch
* Parsing user input with Integer.parseInt() and Double.parseDouble()
